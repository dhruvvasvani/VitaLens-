# PerfAgent: AI-Powered Real User Monitoring - 3-Minute Pitch Script

[0:00 - 0:30] INTRODUCTION: The Problem & Solution
"Hello! Today I'm excited to show you our project, PerfAgent. 

Every modern web developer knows that frontend performance is critical. Google uses 'Core Web Vitals' to rank websites, meaning slow websites literally lose traffic and money. But the problem is that tracking these metrics is difficult, and when a metric is failing—like a slow 'Largest Contentful Paint' or a bad 'Cumulative Layout Shift'—developers often don't know exactly how to fix the code to solve it.

That is the exact problem we solved. PerfAgent is an AI-powered Real User Monitoring tool. It doesn't just show you that your app is slow; it uses AI to give you the exact code you need to make it fast."

[0:30 - 1:15] ARCHITECTURE: How we built it
"Let me explain how it works under the hood. 

Our application is split into two parts:
First, the Frontend Dashboard is built using Next.js 14 with the App Router, providing a highly responsive, real-time UI. 
Second, our Backend is a high-performance Python FastAPI server connected to a database that stores the performance data. 

But the real magic happens through our integration with Google's Gemini 2.5 Flash model. We inject a tiny JavaScript tracking snippet into the target website. As users navigate the site, their browser performance data is sent back to our server in real-time over WebSockets."

[1:15 - 2:00] THE DASHBOARD: Visualizing the Data
"When you open our dashboard, you get a bird's-eye view of your application's health. 

You can see live WebSocket events streaming in as users interact with your site. We track the 'Big 5' performance metrics: LCP, CLS, INP, FCP, and TTFB. We have visual indicators like CWV Radar charts and hourly average graphs so you can spot regressions immediately. 

If there is a sudden spike in layout shifts, or if JavaScript errors are blocking the main thread, the dashboard captures all of that and raises an alert if it violates your set performance budget."

[2:00 - 2:45] THE 'CODE BOOST': The AI Analyzer
"But showing data is what old analytics tools do. Here is where PerfAgent stands out: our 'AI Agent Analysis'.

When a metric like Largest Contentful Paint (LCP) is performing poorly, you can click 'Fix' or run a full AI Analysis. Our backend takes all the aggregated performance data, JavaScript errors, and navigation timings, and feeds them into the Gemini 2.5 Flash model as a Senior Performance Engineer.

The AI analyzes the bottlenecks and provides what we call a 'Code Boost'. Instead of generic advice, it gives you a copy-pasteable Next.js code fix. For example, if images are loading slowly, it won't just say 'optimize images'—it will rewrite your HTML image tag into an optimized Next.js `<Image>` component with the `priority` flag enabled. It literally writes the performance fix for you."

[2:45 - 3:00] CONCLUSION: Impact
"In conclusion, PerfAgent transforms performance monitoring from a passive dashboard into an active, AI-driven team member. It saves developers hours of debugging by directly linking real-world performance issues to actionable code solutions. 

Thank you, and I'd be happy to show you a quick demo of the dashboard and the AI Code Boost in action!"
